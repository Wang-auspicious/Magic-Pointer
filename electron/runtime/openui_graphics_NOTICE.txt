Magic Pointer OpenUI drawing extension

Renderer: electron/renderer/openui_graphics.ts
Global API: OpenUIGraphics.extend(bundle)
The factory derives and caches a library from the official browser bundle. It
uses public component schemas and library.extend; the vendored code is unchanged.

Components: Svg, SvgCircle, SvgRect, SvgLine, SvgPath, SvgText, SvgGroup.
Svg is supported in Card, SectionItem, TabItem and AccordionItem content.
SvgGroup can contain shapes and nested groups. Reactive expressions are evaluated
by the official OpenUI renderer. No alternate DSL interpreter is included.

Schema resource: openui_graphics_prompt.txt
Generated from the actual extended library's toSpec().components. It contains
only newly added components and parent signatures changed by the extension,
formatted as signature + " — " + description. Regenerate after changing a
schema; merge these entries by component name with the vendor's prompt so the
updated parent content unions replace the original signatures.

Drawing values are mapped to explicit React SVG attributes. Numbers must be
finite; sizes are nonnegative. Paint accepts named/hex/rgb/hsl CSS colors,
currentColor and none, never URLs or arbitrary CSS variables. Path commands and
group transforms are restricted to SVG drawing syntax. Text is a React text
child. No raw markup, external image references or event-handler strings are
accepted by these components.
