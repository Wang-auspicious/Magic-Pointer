# 发布排期决策说明

## 一、材料冲突与取舍

材料B明确声明"后发修订，覆盖冲突"，因此：

1. 预算由材料A的 17,000 元调整为材料B的 18,000 元。
2. 材料B新增唯一加速选项（C从4日缩至3日，额外2,000元），材料A无此选项，取材料B。
3. 其余约束（工作日规则、任务定义、依赖关系等）两材料一致，无冲突。

## 二、原方案（v1，不加速）是否达标

v1方案基于材料A全部原始条件排期：

- 任务A结束 9/22 → B、C均从 9/24 开工
- B结束 9/28，C结束 9/29 → D从 9/30 开工，结束 10/1
- E从 10/2 开工，跨周末至 10/5 结束
- F从 10/6 开工，结束 10/6

F结束日期为 10月6日，超过截止日期 10月5日 一天。原方案无法按期完成。

原因分析：C的4工作日是关键路径瓶颈，与B并行后C多出1天，导致D延后1天，整条链推移至超期。

## 三、满足最终要求的最低成本方案（v2）

唯一加速手段是将C从4日缩至3日（额外2,000元）。加速后：

- C与B同时在 9/28 结束 → D从 9/29 开工，结束 9/30
- E从 10/1 开工，结束 10/2（恰好利用10/1、10/2两个特殊工作日）
- F从 10/5 开工，结束 10/5（deadline当天）

项目结束日期恰好为 10月5日，满足截止要求。

此方案是唯一可选加速手段，不存在更低成本的替代方案。

## 四、费用汇总

| 项目 | v1（不加速） | v2（加速） |
|------|------------|-----------|
| 固定费用合计 | 15,800 | 15,800 |
| 额外费用 | 0 | 2,000 |
| 总费用 | 15,800 | 17,800 |
| 最终预算 | — | 18,000 |
| 剩余预算 | 2,200 | 200 |

## 五、关键路径

v2关键路径：A → C → D → E → F（共10个有效工作日，从9/21至10/5）

其中C是加速点：若C不加速，关键路径延长1天导致超期。B与C并行，B同样需要10个工作日窗口但正好不超，B不在关键路径的瓶颈位置（B结束 9/28，C加速后也结束 9/28，两者同时释放D）。

## 六、结论

采用v2方案：支付额外2,000元加速任务C，总费用17,800元，在18,000元预算内剩余200元，项目于10月5日按期完成。
