# 爬取 claude.ai 的 Code 视图（执行手册）

给接手的 agent。读完 §0 就能明白为什么必须爬，§1 是产物格式，§2 是取数通道，
§4/§5 是必须覆盖的清单，§6 是验收。

---

## 0. 背景与边界

**为什么必须爬。** 本地 Claude Desktop 的安装包里**没有** Code 视图。已核实：
18MB 的 `.vite/build` 里 grep `Type / for commands`、`Create PR`、`What's up next`、
`Start a side chat`，命中数全是 0。Code 视图是运行时从 claude.ai 拉下来的。
所以图标 path、DOM 结构、CSS 数值**都不在磁盘上**，只能从活着的页面里取。
`参考claude设计/*.png` 那 22 张截图是唯一现有的参照，分辨率不够反推数值。

**边界。** 这是你自己账号、你自己机器上的界面快照，只用于本仓库的 UI 复刻。
产物文件里**不许**出现：cookie、token、org id、对话内容、用户名。
抓的时候用**一个空会话**，别抓你正在用的那个。

**纪律：原样抄，不要重画。** 仓库里 `electron/renderer/dsh_icons.ts` 的文件头就是这么
写的：

> The path data and view boxes below are copied verbatim. This module only adapts
> React SVG elements to Magic Pointer's native-DOM renderer; it does not redraw or
> geometrically approximate the icons.

任何「我觉得这样更像」的几何近似都算不合格。拿不到就不放，不要造。

## 1. 产物落盘格式

```
参考claude设计/scraped/
  README.md              版本号、日期、窗口尺寸、devicePixelRatio、系统缩放
  dom/
    code-view.html       脱敏后的 outerHTML
    home.html
    settings.html
  css/
    stylesheets.css      所有规则拼接（见 §3.2）
    tokens.json          所有 --* 自定义属性的值
    computed.json        组件 → 计算样式表（§4 的键）
  icons/
    manifest.json
    <name>.svg           每个图标一个文件，原样 <svg>
  motion/
    <name>.json          关键动画的 animation/transition 明细
  states/
    <name>.png           每个状态一张图（§5）
```

### `icons/manifest.json`

```json
{
  "claudeVersion": "1.1.3918",
  "capturedAt": "<日期，抓的时候填>",
  "viewport": { "width": 1199, "height": 800, "dpr": 1 },
  "icons": [
    {
      "name": "copy",
      "source": "button[aria-label=Copy]",
      "viewBox": "0 0 24 24",
      "node": "<svg …>…</svg>",
      "context": "message action row",
      "count": 3
    }
  ]
}
```

命名规则：

- **按功能**，kebab-case。`copy` 不叫 `two-squares`，`retry` 不叫 `arrow-circle`，
  `branch` 不叫 `git-fork`。
- 同一图标出现多次只留一条，`count` 记次数。
- `node` 是**原样的** `<svg>` 序列化串，必须含 `viewBox`、`fill`、`stroke`、
  `stroke-width`、`stroke-linecap`、`stroke-linejoin`、`fill-rule`、`clip-rule`、
  `transform`。少一个属性就可能从实心变描边。
- 拿不到 `aria-label` 时依次退：最近的 `data-testid` → `title` → 父按钮文本 →
  按位置命名 `unknown-01` 并在 manifest 里附上截图坐标，方便人肉认领。

## 2. 取数通道：CDP（首选）

**先确认 Desktop 到底装没装。** 本机现状（2026-09-17 实测）：`%APPDATA%\Claude\`
这个 userData 目录在，但里面 `logs\main.log` 最后一次写入停在 2026-08-21；
`%LOCALAPPDATA%\AnthropicClaude\`（Squirrel 的安装位置）、
`AppData\Local\Programs\`、`D:\` 三层以内都没有 `Claude.exe`。也就是说
**这台机器上现在很可能没装 Desktop**，`参考claude设计/` 里那批哈希名 PNG
看起来是下载来的，不是本机截的。

所以第一步是二选一：

- Desktop 装了 → 走通道 A（下面这一节）。
- 没装 → 走通道 B：在**浏览器**里打开 claude.ai 的 Code 视图，用同一个 CDP 手法
  抓（Chrome 用 `--remote-debugging-port=9222` 启动，然后同样
  `curl http://127.0.0.1:9222/json` 挑 `claude.ai` 那条）。这条要用你自己的登录态，
  抓到的产物照样要脱敏。

Claude Desktop 是 Electron。用它自己的远程调试端口抓，**不用登录、不用爬虫、不用 cookie**。

**2.1 退出 Claude**，托盘图标也退（Electron 有后台常驻）。

**2.2 找到 exe：**

```powershell
$exe = Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Uninstall\*' |
  Where-Object { $_.DisplayName -like '*Claude*' } |
  Select-Object -ExpandProperty InstallLocation -ErrorAction SilentlyContinue
$exe
# 兜底：直接找
Get-ChildItem "$env:LOCALAPPDATA\AnthropicClaude","$env:LOCALAPPDATA\Programs" -Recurse `
  -Filter 'Claude.exe' -ErrorAction SilentlyContinue | Select-Object -First 1 -ExpandProperty FullName
```

**2.3 带调试端口启动：**

```powershell
& $exePath --remote-debugging-port=9222
```

**2.4 列出目标：**

```bash
curl http://127.0.0.1:9222/json
```

挑 `type: "page"` 且 `url` 含 `claude.ai` 的那条，记下 `webSocketDebuggerUrl`。
Claude 有几个窗口（主窗、预览窗、buddy 窗），**别抓错**。

**2.5 连上去。** Node 18+ 自带 `WebSocket`，不需要 puppeteer：

```js
// tools/scrape_claude.js  —— 一次 eval，把结果写到 §1 的目录
const ws = new WebSocket(process.argv[2]);
let id = 0;
const pending = new Map();
const call = (method, params) => new Promise((resolve) => {
  const n = ++id;
  pending.set(n, resolve);
  ws.send(JSON.stringify({ id: n, method, params }));
});
ws.addEventListener('message', (event) => {
  const msg = JSON.parse(event.data);
  if (pending.has(msg.id)) pending.get(msg.id)(msg.result);
});
ws.addEventListener('open', async () => {
  const result = await call('Runtime.evaluate', {
    expression: EXTRACT_SOURCE,   // §3 的那段
    returnByValue: true,
    awaitPromise: true,
  });
  console.log(JSON.stringify(result.result.value, null, 2));
  ws.close();
});
```

**2.6 截图**用 `Page.captureScreenshot`（`{ format: 'png', captureBeyondViewport: false }`），
返回 base64，落盘到 `states/`。抓之前先 `Page.enable`。

**通道 B**（CDP 不通时）：`Page.navigate` 到你自己的 claude.ai Code 视图，带登录态跑同一段
`EXTRACT_SOURCE`。这条要 cookie，尽量不用。

## 3. 抓什么

### 3.1 DOM

`document.documentElement.outerHTML`。抓完**立刻脱敏**：把所有文本节点换成
`«text»`（保留元素嵌套与属性，丢内容）。写进 `dom/*.html` 的必须是脱敏后的版本。

元素是按状态渲染的 —— 折叠的工具组和展开的工具组在 DOM 里不是同一棵子树。
所以每个状态抓一份（§5）。

### 3.2 CSS

Claude 用 constructable stylesheets，只读 `document.styleSheets` 会漏。三处都要：

```js
const rules = [];
for (const sheet of document.styleSheets) {
  try { for (const r of sheet.cssRules) rules.push(r.cssText); } catch {}
}
for (const sheet of document.adoptedStyleSheets || []) {
  for (const r of sheet.cssRules) rules.push(r.cssText);
}
const inline = [...document.querySelectorAll('style')].map((s) => s.textContent).join('\n');
```

自定义变量：遍历 `getComputedStyle(document.documentElement)`，收 `--` 开头的键值，
写 `tokens.json`。

**计算样式快照是这次最重要的一项。** 视觉差异九成不在结构上，而在
`padding` / `gap` / `line-height` / `letter-spacing` / `border-radius` / `font-size`
这几个数上——这些从截图里量不出来，只能读。对 §4 每个组件，在**打开和关闭两种状态**下
都取一遍**全量**属性（属性名用 `[...style]` 枚举，别手写白名单），写 `computed.json`：

```js
function snapshot(selector) {
  const el = document.querySelector(selector);
  if (!el) return null;
  const style = getComputedStyle(el);
  const out = {};
  for (const key of style) out[key] = style.getPropertyValue(key);
  out.__rect = el.getBoundingClientRect().toJSON();
  return out;
}
```

### 3.3 图标

```js
[...document.querySelectorAll('svg')].map((svg) => ({
  html: svg.outerHTML,
  label: svg.closest('button')?.getAttribute('aria-label') || svg.getAttribute('aria-label') || '',
  testid: svg.closest('[data-testid]')?.dataset.testid || '',
  text: (svg.closest('button') || svg).textContent.trim().slice(0, 40),
  rect: svg.getBoundingClientRect().toJSON(),
}));
```

`<use href="#x">` 引用的，要把对应的 `<symbol>` / `<defs>` 一起导出，否则拿到的是一串空壳。

闭包里的圆角矩形 `/` 文字图标不是 `<svg>`，是字体图标或伪元素 —— 遇到就记进
manifest 的 `"kind": "css"` 并附上伪元素的 `content` 和 `font-family`。

## 5. 状态清单（每个一张 PNG + 一份 DOM）

1. 空会话 Home
2. 会话中：全部折叠
3. 会话中：展开一个工具组
4. 会话中：展开一个出错工具
5. 运行中（星芒 + 计时 + 阶段名）
6. 消息 hover（动作行出现）
7. 消息 hover 离开后（动作行消失）
8. 每个 popover 打开各一张：context / model / effort / permission / 附件 / 文件夹 / 账号
9. 设置模态
10. 侧栏含多个项目、含未读点
11. 权限卡出现（待回答）
12. 权限卡回答后

每张图的文件名用状态的 kebab-case，和 `states/` 里的对应。

## 6. 验收

1. `icons/*.svg` 能直接塞进 MP 的精灵（`electron/renderer/icons.ts` 那个
   `<svg class="icon-sprite">`），渲染出来和 `states/*.png` 里的同名图标**像素级重合**。
   验法：把两张图裁到同一区域，叠一张 diff。
2. `tokens.json` 里每个 MP 已经用到的 token 都能在 `electron/renderer/claude_chat.css`
   里找到对应变量；缺的列成表。
3. 写一份 `docs/scraped-diff.md`：逐组件列 MP 现状 vs 抓取结果，差异按
   「数值差 / 结构差 / 缺失」三类标，数值差给出两个数。
4. **抓取和移植分两个 PR。** 这次只交 `参考claude设计/scraped/` 和
   `docs/scraped-diff.md`，不许动 `electron/`。
