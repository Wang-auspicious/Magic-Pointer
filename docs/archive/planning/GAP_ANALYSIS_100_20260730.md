# Magic Pointer 100 条漏洞清单 + Kimi 66 条对照整合

更新时间：2026-07-30
定位：面向 GitHub Release 分发（Windows exe / macOS pkg，自动更新）的开源桌面代理。
对标：Claude Code CLI 的工程严谨、Hermes 的模块化 / skills、Codex app-server 的会话协议、electron-updater 生态实践。

漏洞定义：任何一条只要"标准开源桌面产品应有而当前没有 / 不完整 / 有隐患"就算，不分严重与否。每条都给"现状 → 该改成什么"两句，方便直接落地。

## 一、打包与分发（1–15）

1. **仅 Windows 有 CI，macOS 无发布流水线。** 现状：`.github/workflows/` 只有 `release-windows.yml`。改：新增 `release-macos.yml`，用 `macos-14` runner 跑 `electron-builder --mac dmg,zip`，Apple ID 通过 secrets 注入。

2. **Windows 未做代码签名，`CSC_IDENTITY_AUTO_DISCOVERY: 'false'`。** 现状：安装包会触发 SmartScreen 警告。改：至少接入 Azure Trusted Signing 或 SignPath 免费 OSS 计划，`electron-builder.yml` 里配 `win.signAndEditExecutable`。

3. **macOS 未做公证 / notarize。** 现状：native host README 只写 `swiftc -O`，无签名链路。改：`build.mac.notarize` + `hardenedRuntime: true` + `entitlements.mac.plist`（NSMicrophoneUsage / NSAppleEventsUsage / NSAccessibilityUsage）。

4. **无 SBOM。** 改：CI 里跑 `@cyclonedx/cyclonedx-npm` + `cyclonedx-py`，产物随 release 一起上传。

5. **无依赖漏洞扫描。** 改：加 `dependabot.yml`（npm + pip）+ `pip-audit` step + `npm audit --audit-level=high` gate。

6. **`asar: false` 但没有校验二进制完整性。** 现状：Python 脚本裸露在 resources 里，用户可编辑。改：产品化时开 `asar: true` + `asarUnpack` 只解压 Python 桥，配 `electron-updater` 的 SHA512 校验。

7. **electron-updater 无差分升级配置。** 改：`nsis.differentialPackage: true`，Mac 用 `mac.electronUpdaterCompatibility: '>=2.16'`。

8. **更新通道单一。** 改：加 `beta` / `stable` 双通道，Dashboard 里给用户切换开关，`updater.channel = 'beta'`。

9. **releases 未强制 GPG / minisign 签名。** 改：CI 用 `minisign -Sm` 对 exe/dmg 追加签名，README 附公钥。

10. **无卸载器清理钩子。** 现状：NSIS 默认卸载器不清 `%LOCALAPPDATA%\Magic Pointer`，用户数据变孤儿。改：写 `installer.nsh` 的 `un.onInit` 询问是否清用户数据。

11. **无 portable 模式。** 改：`electron-builder.yml` 加 `portable` target，配合 `--portable` 环境变量把用户数据放到 exe 同目录。

12. **未考虑 Windows Store / Winget 分发。** 改：先做 `winget-pkgs` manifest，一份 YAML 自动同步版本号。

13. **Homebrew Cask 未注册。** 改：加 `homebrew-cask` PR 模板，`cask "magic-pointer"`。

14. **Node/Python 版本未 pin 到 `.nvmrc` / `.python-version`。** 现状：CI 写 Node 24 / Python 3.12，本地 dev 靠嘴传。改：加两个文件。

15. **build 目录 `python-wheelhouse.staging-*` 遗留多份未清理。** 现状看到 3 份 staging。改：`prepare_python_runtime.ps1` 结束 finally 里递归删旧 staging。

## 二、代码组织与可维护性（16–28）

16. **`electron/main.js` 3255 行单文件。** 改：按职责拆 `main/app.js`、`main/ipc.js`、`main/windows.js`、`main/updater.js`、`main/pointer.js`，主文件只做 bootstrap。

17. **`electron/renderer/dashboard.js` 2417 行单文件。** 改：拆成 `dashboard/nav.js`、`dashboard/sections/*.js`，用原生 ES module `<script type="module">` 装载。

18. **`app/fabric/engine.py` 790 行 God Class。** 改：把 provider 路由、capability 检查、审计三块分成 `engine_router.py` / `engine_gate.py` / `engine_audit.py`。

19. **`electron/` 下模块混合了策略与副作用。** 改：`*_policy.js` 保持纯函数（现在多数已是），带 IPC 的挂到 `main/`。

20. **`scripts/` 里 Python 脚本没有共用入口。** 现状：`agent_bridge.py` / `agent_hook_bridge.py` / `fabric_bridge.py` 各写一遍 stdio 编码修正。改：抽 `scripts/_bridge_common.py`，提供 `force_utf8_stdio()` / `read_json_line()`。

21. **`app/actions/executor.py` 745 行，Recipe 分发靠 if/elif 长链。** 改：把每个 Recipe 落到 `app/actions/recipes/<id>.py`，用装饰器注册到 `RECIPE_HANDLERS`。

22. **无 `.editorconfig`。** 改：加一份统一缩进 / 换行。

23. **无 Prettier / ESLint 配置。** 改：加 `.prettierrc` + `eslint.config.mjs`（`electron`, `no-restricted-globals` 等）。

24. **Python 无 ruff / black。** 改：`pyproject.toml` 里配 ruff（line-length=100, select=E,F,I,B）。

25. **无 pre-commit。** 改：加 `.pre-commit-config.yaml` 跑 ruff / prettier / eslint / trailing whitespace。

26. **`requirements.txt` 与 `requirements.lock.txt` 双份且非工具生成。** 改：换成 `uv` 或 `pip-tools`，`requirements.in → requirements.lock.txt` 由 CI 生成。

27. **`node_modules` 里 electron 43 与 electron-updater 6，未锁 `overrides`。** 改：`package.json` 加 `"overrides"` / `"resolutions"` 保证 transitive 版本。

28. **未定义 `engines` 字段。** 改：`"engines": { "node": ">=20 <25", "electron": ">=43" }`。

## 三、错误处理、可观测性、崩溃上报（29–40）

29. **无 `crashReporter` 启用。** 改：`app.js` 里 `crashReporter.start({ submitURL: '', uploadToServer: false })`，本地保存 `.dmp`，Dashboard 「诊断」页出示。

30. **无结构化日志。** 现状：多数用 `log()` / `console.error`。改：抽 `main/logger.js`，JSON Lines 写到 `%LOCALAPPDATA%\Magic Pointer\logs\`，按天滚动。

31. **Python 侧 print/traceback 没进日志。** 改：`scripts/_bridge_common.py` 统一 `logging.basicConfig` 到同一目录。

32. **无遥测开关（默认关闭 + 可选加入）。** 改：Dashboard「隐私」页加"匿名崩溃统计"toggle，默认关闭；仅上传 hash 化事件类型。

33. **electron-updater 错误只 dialog 一次。** 现状：见 `update_manager.js`。改：错误累计到状态栏红点 + 「诊断」页展开原因。

34. **preflight 失败无自愈。** 改：识别常见 case（Whisper 缺、pywin32 缺）→ 弹一键修复按钮。

35. **无健康检查端点。** 改：给 Fabric bridge 加 `--health` 参数返回 JSON，Dashboard 每 5s 拉一次。

36. **无 uncaughtException / unhandledRejection 拦截。** 改：`main.js` 顶部 `process.on('uncaughtException', ...)` → 日志 + friendly dialog + `app.relaunch()`。

37. **`spawn` 子进程无监控。** 现状：voice worker / python bridge 崩了只靠自身重启计时器。改：加 `child.on('exit')` 计数，5 分钟内 >3 次崩溃就熔断 + 提示用户。

38. **审计事件未做敏感字段脱敏。** 现状 blueprint 8.1 提到审计，但 executor 里 audit payload 里可能有 prompt 全文。改：`app/fabric/audit.py` 加 `_scrub_pii()`（email/phone/URL 正则）。

39. **无 Sentry-lite 本地视图。** 改：Dashboard「活动」页支持按 `error / warn / info` 过滤 + 复制堆栈。

40. **无版本 diagnostics dump。** 改：Ctrl+Alt+Shift+D 一键生成 `.zip`（脱敏日志 + settings.json + capability_snapshot），用户提 issue 直接附上。

## 四、安全（41–54）

41. **`safeStorage` 未做 fallback 提示。** 现状：`credential_store.js` 直接调用。改：`safeStorage.isEncryptionAvailable()` 为 false 时弹出说明，写明"当前使用明文，风险 X"。

42. **Windows 上的密钥没有绑定当前用户 SID。** 改：credential store 里加 `dpapi` scope=CurrentUser，切用户能自动失效。

43. **`spawn` 参数曾拼字符串风险。** 现状：多数用 argv 数组（正确），但 `pointer_input_state.ps1` / `office_selection_probe.vbs` 用 `spawn(shell, ['/c', ...])`。改：统一走数组、禁 `shell: true`。

44. **PowerShell / VBS 脚本无签名校验。** 改：安装时把 hash 写进 `data/preflight_manifest.v1.json`，启动前对比，防篡改。

45. **MCP stdio server 无鉴权。** 现状：任何本机进程读 stdin 都能触发。改：`magic_pointer_mcp.py` 支持 `--token`，Dashboard 生成随机 token，Agent 配置里注入。

46. **`current-object.json` 明文落盘且可能含选中文本。** 改：加 `SettingsStore.privacy.encryptCurrentObject`，默认对 `content` 字段用 `safeStorage.encryptString`。

47. **未设 CSP。** 现状：`dashboard.html` / `panel.html` 无 `<meta http-equiv="Content-Security-Policy">`。改：`default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:`。

48. **`preload.js` 挂到 window 的 API 未白名单收敛。** 改：`contextBridge.exposeInMainWorld('magicPointer', { onEpisode, invoke })`，`invoke` 只允许固定 channel 集合。

49. **`webPreferences` 未强制 sandbox。** 改：所有 `BrowserWindow` 设 `sandbox: true, contextIsolation: true, nodeIntegration: false, webSecurity: true`。

50. **允许 `openExternal` 未过滤 scheme。** 改：`shell.openExternal` 之前只放行 `https:` / `mailto:` / `tel:`；`file:` 走 `shell.openPath`。

51. **`route_policy.js` 生成 maps URL 未做 open-redirect 校验。** 改：`isAllowedGoogleMapsDirectionsUrl` 白名单严格到 host + path。

52. **无 anti-tamper 检查 Python 桥。** 改：安装时 `data/preflight_manifest.v1.json` 记录 python bridge scripts 的 SHA256，运行前对比。

53. **没有 GitHub `SECURITY.md`。** 改：加一份，写明报告渠道（邮箱 or GH advisory）。

54. **无 CodeQL / Semgrep。** 改：`.github/workflows/codeql.yml`（JS/Python）+ `semgrep-action`。

## 五、跨平台 / macOS（55–63）

55. **`native/macos/MagicPointerHost.swift` 只有 118 行样例。** 改：完善到能持续输出 `pointer`, `keys`, `scroll`, `foreground` JSONL，接住 `stdin` 的 `--pause` / `--resume`。

56. **`MagicPointerHost` 未打包成 `.app` bundle。** 改：产 `MagicPointerHost.app`，`electron-builder` 的 `extraResources` 带进去。

57. **未接入 macOS `NSAccessibility` 拉选区。** 改：新增 `native/macos/ax_selection.swift`，返回 `bundleIdentifier / role / value / bbox`，桥到 `app/adapters/`。

58. **未接入 `ScreenCaptureKit`。** 改：视觉兜底 pipeline 走 SCK，`native/macos/screencap.swift`。

59. **Blueprint 8.1 声称"macOS 未实机验证"，仓库无 macOS 测试环境证据。** 改：CI 加 `macos-14` job 至少跑单元 + swiftc build。

60. **Linux 未列入路线图。** 改：README 说明当前不支持 Linux；顺便留 `linux` target 占位（Wayland 输入策略仍在演进）。

62. **macOS Universal 二进制未指定。** 改：`mac.target: [{ target: 'dmg', arch: ['x64', 'arm64'] }]`。

63. **`pointer_input_state.ps1` 依赖 Add-Type，冷启动慢。** 改：编译成 `.exe`（PowerShell → C# → `csc.exe`），随包分发。

## 六、Dashboard / UX（64–72）

64. **Dashboard 无搜索结果高亮。** 现状：`sidebar-search` 输入不联动。改：`dashboard/nav.js` 加 fuzzy match + `<mark>`。

65. **Dashboard 长表格无虚拟滚动。** 改：`Activity` / `Capabilities` 页超 200 行时启用 `<virtual-scroller>`（原生 CSS `content-visibility`）。

66. **Dashboard 无深浅色主题切换按钮。** 现状：跟随 `nativeTheme`。改：加显式三态（跟随/浅/深），保存到 settings。

67. **Onboarding 完成后无"复查"入口。** 改：Dashboard「通用」页加"重新运行首启向导"按钮。

68. **快捷键冲突未检测。** 改：`globalShortcut.register` 失败时提示用户改键，Dashboard 现场标红。

69. **无 tray 菜单 "Pause 15 min"。** 改：托盘菜单加"暂停 15/60 分钟"+ Do Not Disturb 联动。

70. **无按应用禁用界面。** 现状：Blueprint 里承诺"敏感应用禁用"，但 dashboard 里未见 UI。改：`apps` 视图加白/黑名单表 + 拖拽 exe 图标即可加入。

71. **气泡在多显示器上偶发定位错位。** 现状：见 `panel_position.js` / `coordinate_space.js`。改：加 per-display 校准 + `screen.dipToScreenPoint`。

72. **无键盘辅助操作。** 改：Ctrl+Alt+Space（气泡焦点）+ Tab 遍历，符合 WCAG。

## 七、语音与本地能力（73–80）

73. **Whisper 模型缺失只弹气泡错误，不提供下载入口。** 改：Dashboard「语音」页加"下载 tiny / base / small"按钮，走 huggingface mirror（用户可换 mirror）。

74. **`openai-whisper==20250625` 版本 pin 但没验证权重。** 改：下载后校验 SHA256，与 `data/model_capabilities.v1.json` 记录对比。

75. **无 VAD（静音自动提交）。** 改：`local_voice_worker.py` 引入 `webrtcvad`，静音 800 ms 自动 `stopListening`。

76. **无 partial 转写显示。** 现状：气泡里只显示 final。改：worker 输出 `partial` 事件，UI 逐字增长。

77. **无中英混合的分词修正。** 改：`app/voice/text_normalization.py` 支持简单 opencc 转繁 + 常见口误修正规则表。

78. **RapidOCR 单一后端。** 改：新增 `PaddleOCR` / macOS `Vision` 后端注册到 `app/adapters/registry.py`，按平台自动挑。

79. **OCR 结果无置信度过滤。** 改：`min_confidence` 可在 Dashboard 调，默认 0.6。

80. **无本地 TTS 回读。** 改：Windows 走 SAPI，macOS 走 `NSSpeechSynthesizer`，Recipe `text.speak_this` 就可以本地闭环。

## 八、Recipe / Agent / MCP（81–91）

81. **Recipe catalog 硬编码于 `catalog.py`。** 改：拆到 `app/fabric/recipes/*.yaml`，`public_recipe_catalog()` 运行时加载 + JSON Schema 校验。

82. **Router 用中文关键词硬编码。** 现状：`router.py` 里 40+ 短语。改：抽 `data/recipe_keywords.zh.yaml` / `.en.yaml`，允许用户在 Dashboard 增补别名。

83. **Recipe 无版本号。** 改：每个 recipe 里加 `version:` 字段，审计事件记录使用的版本。

84. **Recipe 缺 dry-run 模式。** 改：`FabricEngine.plan(recipe, dry_run=True)` 返回预期动作 JSON，Dashboard「能力」页可试运行。

85. **Agent 会话协议只优先 Codex/Pi，Claude/Gemini 走 hooks，未接 ACP。** 改：`app/fabric/agents.py` 里加 `AcpConnector`（Agent Client Protocol），预留 sink。

86. **MCP server 无 tool 分组 / 开关。** 现状：`mcp.py` 里 8 个 tool 全开。改：Dashboard 加 MCP tab，`_TOOLS` 每项独立启用/禁用；持久化到 settings。（这一条与 Kimi 报告的"Codex 风格 tab"合并。）

87. **MCP server 无 `initialize` 里的 capabilities 协商。** 改：按 MCP 规范返回 `serverInfo.name/version` + `capabilities.tools.listChanged: true`，支持 `notifications/tools/list_changed`。

88. **MCP 未 SSE / HTTP。** 现状仅 stdio。改：加 `--transport http --port 0` 可选启动，方便未来 Web IDE 接入。

89. **`agent_hook_bridge.py` 只支持 `claude` / `gemini` 两个 provider。** 改：扩到 `cursor` / `windsurf` / `opencode`，用统一的 `HookAdapter`。

90. **Agent 后台任务 UI 无暂停 / cancel 按钮。** 现状：`fabric/task_store.py` 有状态字段但 Dashboard 未暴露。改：Activity 页每行加操作按钮。

91. **无 Agent 结果自动 diff 预览。** 改：`app/actions/draft_writer.py` 生成结果后走一个 unified diff 组件（Monaco 内联）。

## 九、测试 / 质量（92–96）

92. **`scripts/run-node-tests.js` 是自制 runner。** 改：迁到 `node --test`（Node 20+ 原生）或 `vitest`，产 JUnit XML 供 CI 展示。
