# Magic Pointer：20 个真正可用的工作流

下面的场景都遵循同一交互：把鼠标停在对象上，短促左右晃动；系统先冻结 `THIS`，再
显示一个随语音转写或文字输入逐步生长的气泡。用户只需说出或输入示例短命令。高风险
动作先预览，专用连接器缺失时会明确转交已安装 Agent，不会假装已经在原应用完成。

## 知识工作与普通办公

1. **网页/PDF 证据卡**  
   指向一段结论，说“把这段和来源保存成证据卡”。输出 Markdown，保留应用、路径、
   URL、页码、边框与哈希，适合论文、法务、咨询和竞品研究。

2. **不可复制文字一键取出**  
   指向图片、远程桌面或扫描 PDF 的文字，说“识别文字并复制”。OCR 结果写入剪贴板，
   再读取并比对哈希。

3. **OCR 号码清洗**  
   指向被空格或换行打断的单号/电话，说“去掉号码空格再复制”。使用本地确定性规则，
   不需要模型。

4. **Word/WPS 原位改写**  
   选中文本并晃动，点“原位改写”。先显示前后差异，确认后重新核对文档、范围和原文
   哈希，再写回；恢复只撤销这次 Magic Pointer 修改。

5. **翻译并保持当前位置**  
   选中段落，说“翻译成英文并写回当前位置”。模型只生成替换文本，原生 Office/UIA
   适配器负责目标校验与写回。

6. **网页表格转 CSV**  
   指向表格，说“把这个表格导出 CSV”。优先读取原生表结构，只有没有结构信息时才走
   OCR/视觉；输出包含行列数、源对象和文件哈希。

7. **多个表直接合并**  
   依次指两个表形成 `THIS/THAT`，说“合并这两个表”。系统先核对表头；字段冲突则停止，
   不会静默错列。

8. **图表变成可分析数据**  
   指向图表，说“提取图表数据”。若应用能暴露原生 series，直接导出；否则转给配置的
   digitizer 或 Agent，并附图、对象位置和误差要求。

9. **公式转 LaTeX**  
   指向公式，说“把这个公式转成 LaTeX”。专用数学视觉能力不存在时，连同图片/选区
   锚点交给 Pi/Codex 等 Agent，结果必须保存为可引用 artifact。

10. **海报或邮件转日历**  
    指向时间地点，说“加到日历”。先生成规范化草稿并检查冲突；只有用户确认后创建，
    冲突覆盖需要第二次明确确认。

11. **两个地点直接规划路线**  
    依次指起点和终点，说“从这里到那个地方怎么走”。生成 allowlist 内的 Google Maps
    directions URL，距离与时间交给地图服务计算，不由模型编造。

12. **食谱倍增并形成清单**  
    指向食谱，说“做两倍并整理成采购清单”。单位与数量转为结构化 JSON；写入外部清单
    前仍需确认。

## 设计、图片与无多模态模型

13. **图片对象去背景/模糊/擦除**  
    指向图片中的对象，说“擦掉这个”或“把这个背景去掉”。优先调用图像编辑连接器；
    没有时创建带源图和 bbox 的 Agent 任务。

14. **跨图组合**  
    先指沙发，再指房间，说“把这个沙发放进那个房间”。`THIS/THAT` 保留对象身份，
    输出新文件，不覆盖原图。

15. **视觉风格迁移**  
    依次指参考图和目标图，说“用那张图的风格改这个”。计划记录 source/target ID，
    防止把方向弄反。

16. **FrameCue 式视觉桥**  
    指向界面或图片，说“生成给本地模型的视觉提示”。输出 JSON：对象、文字、bbox、
    结构和来源；无多模态 Coding Model 也能收到可定位的视觉上下文。

17. **画布对象就地变化**  
    在 PowerPoint/Figma 类画布指对象和目标位置，说“把这个移到这里”或“改成橙色”。
    原生插件优先；视觉点击只作为带范围、可校验的兜底。

18. **视频里的地点转行动**  
    暂停视频并指餐厅，说“这是哪家店，给我路线”。先保留视频帧证据，再生成地图/订位
    草稿；不会自动订位或付款。

## 开发者与 Agent 协作

19. **运行现场直接交给 Coding Agent**  
    指向真实应用里的错位按钮、错误提示或终端输出，说“让 Codex 修这个”。Magic Pointer
    传递窗口、截图、对象锚点、工作区与用户期望；Agent 自己检查仓库定位源码，不要求用户
    先报三个文件。

20. **后台 Agent 长任务**  
    指向需求或错误，说“交给 Pi 在后台处理，完成后给我回执”。任务有 ID、状态、日志、
    取消与 steer 接口；Dashboard 和 MCP 都能读取状态。

## 组合示例

`THIS/THAT/THESE/HERE` 不是提示词花活，而是跨应用对象引用：

```text
网页里的表格（THIS）
  → “导出 CSV”
  → PowerPoint 的图表占位区（HERE）
  → “把刚才的数据放到这里并生成折线图”
```

```text
真实产品中的错误控件（THIS）
  → 设计稿里的正确控件（THAT）
  → Codex 输入区域（HERE）
  → “按那个参考修复这个，跑测试后给回执”
```

首次体验建议使用第 1、4、6、16 或 19 个场景，它们分别验证来源锚定、原位写回、
结构化提取、无多模态桥和真实 Agent handoff。
