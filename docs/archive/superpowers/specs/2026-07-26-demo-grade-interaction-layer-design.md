## 0. 本轮目标

把 Magic Pointer 的**体验层**做到 Google "pixels to actionable objects" 演示的水准,同时消灭 Terra-high 判定的三个 No-ship 阻塞项。后端底座(Recipe、Whisper、RapidOCR、Agent 通道、Episode)不重建,只对接。

**三个阻塞项(必须闭环):**
1. 截图隐私开关未完全约束 Agent 附件 → 隐私策略单一收口点
2. Agent 排队被错误表述为"完成" → 诚实状态机
3. 结果界面旧交互残留 → 旧表面退役

## 1. 产品哲学复审结论(不变 + 两处裁决)

核心哲学不变:**默认不可见、指针即意图、单一气泡、跨应用对象层**。

复审 20 张 Google 演示图与逐帧分析后,裁决两处此前文档中的矛盾:

**裁决 A — 悬停徽章(HOVERING: TEXT_NOTES_841)不进产品。**
那是 Google 研究沙盒的调试表面,不是产品交互。产品保持唤醒前完全不可见;唤醒后,指针下的对象才出现实时定位描边(live targeting outline),驻留/点击后冻结发光。

**裁决 B — 建议 chips 只出现在"点选对象"流,不出现在语音流。**
演示 1(静态图)展示了 Visualize/Compare/Synthesize chips,但演示 7-10(webm 逐帧)证明语音流是纯气泡、零 chips。两者不矛盾:chips 是"选中对象后还没说话"时的快捷入口;一旦用户开口或打字,chips 立即让位。语音流永远不弹 chips。

## 2. 架构:PointerStage(单一舞台)

**决策:方案 B——体验层重建为单一舞台渲染器,后端不动。**
(备选 A"原地抛光"到不了演示水准;备选 C"连同对象脚本执行模型全部重构"动了已验证的 285 项测试底座,风险与收益不成比。)

每块显示器一个全屏透明、click-through 的 Electron 窗口(PointerStage),承载**全部**瞬时视觉,替代现在分散的 panel/reader/result 窗口热路径:

### 2.1 舞台元素

| 元素 | 触发 | 行为 |
|---|---|---|
| 定位描边 | 唤醒后指针移动 | 指针下对象 1.5px 电蓝描边,120ms fade,跟随指针实时切换 |
| 冻结发光 | 驻留 300ms 或点击 | 对象 2px 发光描边 + 呼吸动画(2.4s 周期),表示"THIS 已锁定" |
| 命令气泡 | 冻结后 | 近指针胶囊。语音态:72px 波形;转写字母逐个飞入(约 30ms stagger);文字态:176px 输入框。随内容生长,上限 560px |
| 建议 chips | 点选流,气泡空置时 | ≤3 枚,按对象类型派生(图像→对比/整理;文本→改写/翻译/摘要;含日期→加入日历)。用户开口/输入即隐藏 |
| 处理态 | 提交后 | 气泡内 shimmer 扫光 + 真实状态文案(见 §3 状态机,不允许假"完成") |
| 结果卡 | 有结构化结果 | 从气泡锚点展开:日历草稿卡 / 表格对比卡 / 文本草稿卡(带 diff),首版仅此三型 |

### 2.2 写回的诚实原则

Google 演示 15 的"字母飞入便签"发生在它可控的沙盒里。我们不控制外部应用,**不伪造外部应用内的动画**:写回外部应用走既有 UIA 草稿插入(只写草稿不提交),舞台上显示真实进度;飞入动画只用于我们自己的表面(气泡、结果卡)。

### 2.3 动效与视觉语言

- 色彩:石墨黑 `#0E1116` 表面、冷白文字、单一电蓝强调(蓝图既定,不引入紫色渐变/卡片堆叠)
- 动效:入场 ease-out-quint 120-350ms;字母飞入用弹簧曲线;GSAP timeline 驱动气泡生长与结果卡展开
- 空态即无:没有内容时舞台零渲染,回归"默认不可见"

## 3. 诚实状态机(阻塞项 1、2)

### 3.1 Agent 任务状态

`queued → running → needs_confirmation → done | failed`

- 气泡与 Dashboard Activity 只展示真实状态;"已完成"仅在 verify 通过后出现
- 排队中的任务显式标注"排队中(第 N 位)",不允许乐观表述
- Activity 升级为演示 12/13 左栏风格的时间线:意图 → 执行计划 → 校验结果

### 3.2 隐私单一收口点

截图进入 Agent 附件的所有路径收敛到一个策略函数(attachment builder 必经)。截图开关关闭时:
- 附件中不得含截图字节或截图文件路径
- context pack 中的视觉字段降级为 OCR 文本(若 OCR 也被关则为空)
- 单元测试断言出站 payload 零截图残留

## 4. 旧表面退役(阻塞项 3)

PointerStage 落地后,旧 panel/reader/result 窗口从热路径移除,旧交互(残留的按钮/快捷键/窗口态)删除而非隐藏。Dashboard 保留(设置与 Activity 属常驻表面,不属瞬时层)。

## 5. 复用与依赖

- 保留:whisper.cpp、RapidOCR、nut.js、Pi RPC、30 Recipe、Episode(THIS/THAT/HERE)、UIA 草稿写入
- 新增依赖仅 GSAP(渲染进程动效);不引入其他重型库
- 不在本轮:macOS 实机、外部服务连接验收、对象脚本执行模型(Google helpers API 式)重构

## 6. 验证标准

1. 既有 285 项 Python 测试 + 全部前端测试保持绿色
2. 新增:隐私收口点单测(出站零截图)、状态机单测(排队不得表述为完成)、舞台各状态静态测试
3. 每个舞台状态截图证据(唤醒、定位、冻结、语音、生长、处理、结果卡、退场)
4. 真机冒烟:晃动唤醒 → 语音 → 写回草稿全链路
