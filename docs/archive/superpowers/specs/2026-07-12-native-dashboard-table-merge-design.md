# Magic Pointer 原生 Table Merge 设计

日期：2026-07-12

A4 的目标是把 Interaction Episode 中 THESE 绑定的多个真实表格合并为一份可核对 artifact，而不是让模型输出一张看似合理的新表。首版输入支持 TSV、CSV 和标准 Markdown 表格；每个来源必须有非空且唯一的表头、至少一行数据、规则列数，并受 80 列/5000 行单表上限保护。无法解析或行列不规则的来源单独报错，不静默丢单元格。

合并按表头 trim + casefold 对齐，首次出现的拼写作为展示列名；新列按来源顺序追加。每行保留内部 `_source_id`，Dashboard 可以回到原对象，但该内部字段默认不导出。首版是纵向 append，不做基于姓名/ID 的 join；join 必须由用户明确指定键并预览一对多、重复键和冲突，不能把“merge”歧义成覆盖。

Dashboard 下一切片显示来源状态、统一列、前 200 行预览、总行数和列映射。导出 CSV 前对以 `= + - @` 开头的单元格加安全前缀，防止用户在 Excel 打开时触发公式注入；原始值仍保留在本地 artifact 中。导出采用保存对话框和原子写入，只有用户明确选择路径才产生文件。未知编码、超限、重复表头和 ragged row 均 fail closed。
