# 当前交付边界

## 源码与安装包

主执行循环、会话、模型协议、桌面与文档能力已迁至 TypeScript；原生 Windows 操作
继续使用 C#/PowerShell。语音功能暂未加入，界面、设置、依赖及启动链已移除。
请以实际提交和发布说明判断安装包是否包含某项改动。

## 平台与应用

- Windows 是主要开发和验证平台；实际可读取和操作的内容取决于目标应用暴露的接口。
- macOS 原生宿主源码存在，但权限、签名、公证及完整应用行为尚未实机验证。
- Linux 尚未实现系统级指针宿主。
- Office 文档读取、结构化修改和部分原生应用路径已有测试及实机记录；完整多应用
  办公任务尚未全部验收，不应将文件级或协议测试当成所有桌面场景通过。
- Figma 缺少用于发行的真实插件 ID，原生 Design Mode 验收仍未完成。构建可以生成
  插件代码和状态说明，但没有有效 ID 时不会生成可冒充正式插件的 manifest。
- PDF 字符定位优先使用 PDF.js 字形宽度；缺少字形数据时会明确标注估算边界，
  尚未完成真实 PDF 阅读器高亮位置的全场景验收。
- Windows 原生桌面工具不视为 macOS 或 Linux 可用；保留 macOS 指针宿主，其他平台
  的原生应用读取和操作仍须分别实现及验收。

## 长任务与模型

个人活动记录目前只在 Windows 验证。仅覆盖 MP 实际运行并启用记录的时段，以及设置中实际可观察的目录；屏幕样本不是连续录像，文件监听不等于全盘审计。断档、锁屏、不可用来源与保留期限均须以界面和日报的实际记录为准。

工作回顾的原生前台区间只从新版采集开始产生，不会给旧截图补造时长。微信式信息整理仅从保留的屏幕文字提取待核查线索，不读取或解密微信数据库，也无法单凭截图确认发送人、回复关系或承诺状态。Screenpipe 是可选本机接口，需用户已有服务；没有随 MP 内置或启动其采集器。Exa Search 需自行配置密钥，未配置时仍使用现有搜索后端；不把公开 Search 接口等同于闭源 Agent Ultra。

会话分支图不会给缺失时间的旧子代理步骤补造开始时间。子代理状态保留最近80条短轨迹，完整历史仍在自己的持久会话中。2026-09-30这一轮按用户要求只做源码开发、定向检查及独立组件预览，没有运行全量验证或同步安装；这些改动不代表已在安装版验收。

Runtime 已有持久会话、压缩、计划、插话、停止、子任务和恢复机制。
这些机制的自动化回归及有限真实模型验收，不代表跨小时任务、所有服务商和
任意应用均已验证。阻塞网络读取的停止速度仍受传输超时和进程停止机制影响。

模型服务可能限流或不支持某些协议字段、图像输入及推理参数。
工具成功与任务交付被用户接受是不同的验证层次。
