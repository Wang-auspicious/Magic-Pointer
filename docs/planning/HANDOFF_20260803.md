### 1.2 ✅ 已确诊 — 划完线按 Enter 后要等约 5 秒气泡才出来

日志：
```
07:32:46.598  selection session capture start
07:32:51.492  bridge complete selection_snapshot_bridge ok=true   ← 4.9 秒
07:32:51.568  stage renderer state=capsule-text                   ← 气泡这才出现
```

**根因**：气泡在等 `selection_snapshot_bridge.py` 的完整感知（截图 + UIA + OCR + 标注）跑完。这是 AGENT.md 里写的「先冻结+全局截图再出语音球」的直接后果。

**修法**：气泡必须**立刻**出现（乐观渲染），grounding 完成后再回填。基础设施已经存在——`session.groundingReady` 标志和 `dictation:start` 的 3 秒有界等待就是为此设计的。要改的是 `electron/main.js` 的 `beginSelectionSession`：不要等 `attachSnapshot` 才 `stage:show`，先 show 一个 `groundingReady=false` 的气泡，快照回来后再 `stage:update`。

⚠️ 注意不要退回旧 bug：AGENT.md「不要做的事」里有一条「不要让全屏截图的空 content 覆盖结构化读到的 content」。乐观渲染只影响**何时显示气泡**，不得改变 content 的真相顺序。
