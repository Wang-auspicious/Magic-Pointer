## 关键实测数据（避免后人重新踩）

**四类应用的 UIA 真相**（`docs/research/2026-08-04-what-uia-actually-exposes.md`）：

| 应用 | UIA 树 | 能读到划线那行 | 正确路径 |
|---|---|---|---|
| Edge / 网页卡片 | 完整 DOM 映射 | 能 | 树遍历 |
| Windows Terminal | 1 个 TermControl，Name=exe 路径 | 能 | TextPattern.RangeFromPoint |
| 微信 4.x | **8 个节点，消息区无子节点** | **不能** | 只能像素 |

**微信会话列表的行间距**（决定视觉分组阈值）：

- 同一条会话内两行：gap −4 ~ 0 px（ratio ≤ 0）
- 相邻两条会话之间：gap 44 ~ 56 px（ratio 1.05 ~ 1.56）
- 阈值取 0.55；原先写的 1.1 会把 5 条会话并成 1 个

**模型网关**：`api.nghimmo.com` 双协议均可用；`max_tokens=1200` 时实际生成 1198 token 耗时 26.9s，降到 120 只要 12.1s——**上限就是延迟**。网关每次请求前塞约 2.6k token 自有系统提示。
