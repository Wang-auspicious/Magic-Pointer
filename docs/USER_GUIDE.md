# 使用指南

## Work 与收集

Work 与 Code 共用 Magic Pointer 的任务执行能力：Work 侧重资料、文档与桌面交付，Code 侧重源码与验证。两者都在对话工作台继续任务。左栏 Resources（收集）用于保存文字、链接、截图和本地文件；为资料选择项目、用途和备注后，可以交给 MP 整理，再放入项目。原件与交接说明保存在项目的 `references/inbox`，后续项目任务会收到资料提示。

收集页「浏览器」打开已连接的 ego 原生窗口并保留本机登录状态。网页选中文字后返回收录；未选文字则保存链接。此操作只读取当前选文，不会遍历点赞或收藏。X 自动导入需要在「来源」单独配置官方用户 OAuth token，默认关闭；其他平台仍为主动收录。手机配对与自动相册同步尚未接通。

MP 整理本地视频时使用已安装的 ffmpeg/ffprobe 抽取六个时间点，不能代表看完视频或听完音频。已保存材料含明确、唯一 arXiv 链接时，会下载并解析 PDF 后加入阅读；交接时一同放入项目。仅有模糊论文标题时不会猜测下载对象。

## 安装和启动

Windows 10/11 是当前主要支持的平台。可从项目的
[Releases](https://github.com/Wang-auspicious/Magic-Pointer/releases) 查看已发布安装包；
源码版的准备和启动命令见 [开发与构建](DEVELOPMENT.md)。

源码 main 可能包含尚未发布到安装包的改动。请分别核对源码的 `package.json`
和已安装应用版本；相同版本号也不代表两者包含相同提交。

## 配置模型

在设置的模型页面配置服务地址、协议、模型和凭据，再通过工作台模型菜单选择。
支持的协议包括 OpenAI Chat Completions、Responses 和 Anthropic Messages。
模型的图像、上下文长度和推理参数能力取决于实际服务商，不能仅由模型名称推断。
密钥保存在本机，不应提交到 Git。

## 桌面指向

1. 短促左右晃动鼠标唤醒，然后划线或圈选目标。
2. 手势完成时固定画面与窗口身份，再读取结构化内容和必要的图像证据。
3. 输入你的要求；可以加入多处材料，并说明哪些是参考、哪些需要修改。
4. 在运行轨迹中查看工具调用、结果与错误。需要时插话、停止或接管。

冻结画面记录指向时的事实；它不代表目标窗口现在仍处于同一状态。
真正写入时会重新核对目标，结果会区分完成、失败和未验证。

## Studio 工作台

工作台提供对话、项目文件夹、材料收藏、产物、工具轨迹和后台任务。
需要读写项目文件时，先选择对应文件夹；普通问答也可以不绑定项目。
文件编辑、命令和桌面动作由 Magic Pointer 自己的 Runtime 执行。

权限菜单决定工具访问范围与审批方式。Plan 模式先整理方案，批准后进入执行。
遇到审批或反问时，在原卡片上回答；后台子任务的审批绑定该子任务。
停止会请求中断，但已经完成的外部操作不会因此自动撤销。

只有需要单独编辑或复用的内容才成为产物。产物可编辑，修改会更新版本；
普通回答保留在对话中。创建本地产物与发送、发布是不同的动作。

## 收集资料

资料列表可用 Tab 进入，方向键逐项移动，Home / End 到首尾，Enter 打开详情。详情内按 Escape 会先保存修改再回到原资料；保存失败时保留编辑内容并显示原因。列表刷新保留当前卡片，详情刷新保留编辑框的焦点和选区。项目菜单支持方向键、Home / End、Escape 和 Tab；点击菜单外会关闭，Escape 只关闭当前菜单或项目弹窗。

左栏「收集」可以保存文字、链接和文件，并为资料指定项目、用途、备注和下一步。浏览器页打开同一份本机 ego 登录会话，选中文字后回到 MP 收录；没有选文时只保存链接，不代表已阅读网页。

详情中可以自行编辑整理结果，也可以交给 MP 阅读已保存的材料。保存期间继续输入会保留新草稿；若资料已被其他操作更新，MP 保留你的输入并提示冲突，可通过「舍弃草稿并重新加载」查看已保存的版本。整理失败仍保留任务入口，便于检查原因和重试。

「放入项目」将原件和交接说明保存到所选项目目录，并加入下一次项目任务可读取的材料。修改标题、用途、备注或整理内容后，需再次放入项目；原交接文件保留，不会用旧的「已放入项目」标记代表新内容已经投递。点赞、收录和用途建议都不构成自动执行项目任务的授权。

项目页的「项目交接」列出待处理、稍后和已处理资料，可直接阅读交接文件，也可选择明天提醒。交接状态会保存；查看或标记资料不会清除项目输入框的草稿。「已带入任务」表示这一版本的摘要和引用已随任务到达 Runtime 的模型请求阶段，点击可回到对应任务，不代表工作已经完成。只有你标记后才进入「已处理」。

每个会话每次最多带入八条尚未投递的新交接，后续轮次继续带入剩余资料；同一版本不会在该会话的每一轮重复添加。重新整理并放入项目会产生新版本，可再次进入任务。恢复暂停的任务沿用当时保存的交接版本；原件仍作为项目文件供任务按需读取。删除暂停的整理会话后，资料立即显示失败原因并可重试。

来源页会保留尚未保存的收集规则。连接、检查和设置保存期间可继续浏览其他页面；回包只更新来源状态。设置失败会恢复实际保存的开关值；连接失败可在原输入框重试，离开该页不会保留输入的 token。自动检查至少选择点赞或收藏之一，切换账号后检查时间从新账号重新开始记录。

## 工作回顾

工作台左栏的「工作回顾」按日期整理实际工作片段、文件变化与可继续的对话。新的前台区间来自原生应用活动记录；旧历史仅有零散截图时会显示「仅采样」，不推断连续工作时长。每条线索可回到原始画面或文件，同一文件的反复保存合并展示。按键次数与应用统计收在原始记录中；不保存有序键入文本。

「分析这一天」会在 MP 自己的新对话中填入所选日期的分析请求，发送后由当前模型按需读取证据。画面中的请求、承诺或截止日期仅作为待核查线索，不能据此确认是谁承诺、是否未回复或工作已经完成。

默认观察桌面、文档、下载等用户目录和已有项目；可加入其他文件夹或磁盘，也可移除全部来源。范围与不可用目录会在设置中显示。文件只记录路径和元数据变化；缓存/构建目录与记录自身的数据目录会被过滤。文件变化数字是事件次数，同一文件多次保存会产生多次修改。

开启屏幕记录后，电脑活跃时至少间隔 30 秒采样当前窗口，并在本机识字。空闲、锁屏与前台身份变化时不保存该帧。原图和全文可按日期/关键词回看；这是屏幕样本，并非全天视频。

若自己已有运行中的 Screenpipe，可在记录设置开启「补充 Screenpipe 记录」。MP 只读取本机 3030 端口的公开 OCR 接口，并以 MP 已有屏幕时间和窗口身份限定补充范围；不启动 Screenpipe，不读其音频、有序键入或剪贴板。来源状态独立显示；未连接时本地回顾仍可用。暂停记录或删除详情后，不从外部服务补读这些内容。

默认每天本地时间 21:00 保存小结，午夜补齐当天余下记录；未运行时不采集，重新启动后会为已有记录补出尚未生成的日报。详细事件与原图默认保留 30 天，日汇总和客观累计统计继续保留。界面支持暂停、关闭、调整时间/保留天数和删除全部个人活动记录；删除不影响原始文件与对话。

MP 的自有 Runtime 可通过 `Activity.read` 按需读取这些记录，回答“今天 Enter 按了几次”“新增了什么文件”“之前看过哪段内容”。记录默认存本机；通过云模型解释时，所读取的相关文字会作为模型上下文发送，原图是否发送遵守已有的截图上传设置。关闭记录也会关闭后续 Agent 读取入口。不会根据次数自动推断人格，或把历史屏幕中的文字当成执行指令。

## 会话记录

右侧「对话记录」和顶部完整视图共用整段会话的分支轨迹图，替代横向甘特泳道。输入、模型生成、工具调用按真实开始时间排列，子代理以分叉和汇合显示关系。宽视图有模型、单次请求 tokens、耗时与时间列；窄右栏将次要信息放到第二行。

点击事件可展开输入、结果和来源，并定位回原对话；支持搜索、Shift 选取时间范围、调整行密度。已完成会话从开头阅读，进行中且保持在底部时自动跟随。新子代理记录真实逐步时间；旧历史没有时间字段就标为未记录，不按步骤编号编造时间。

## 材料与恢复

当你问“这个按钮在哪”或需要操作指引时，Agent 可用 `point_ui` 在核对当前窗口和目标后显示一个临时指针及短标签。它不移动系统鼠标、不点击；停留后自动退场，也可用 Escape 收起。真正的桌面操作仍走既有授权、执行和结果核对路径。

当前通过文本输入指令，语音功能尚未加入。
收藏材料可显式加入，持续剪贴板采集由用户设置控制。
会话会持久保存计划、来源、工具结果和待回答事项，用于中断后的恢复。
恢复时，对结果未知的外发或不可逆操作需要先核对，不能直接重做。

运行中的同一会话由一个主任务执行；需要补充要求时使用跟进或停止入口，另一个窗口不会再启动竞争任务。`/model` 只切换此会话后续使用的模型，等待回答的卡片与原任务保持不变。用户停止显示为中断，可继续处理。删除前须停止此会话的主任务与后台 Agent；删除等待或失败时仍保留当前会话和输入草稿，只有删除成功才离开该会话。

开启来源的自动整理后，待整理材料会保留在本机队列中。关闭自动整理会暂停后续条目；重新开启后继续处理。应用重启时，已开始的整理仍关联原任务，已有结果会直接恢复，等待回答的任务可从材料详情的「继续整理任务」打开。运行中的任务不会重复启动；排队或整理期间修改、忽略的材料不会被旧结果覆盖。

收集页的「阅读保存的原件」会在应用内打开收录时保留的副本。图片支持点击放大、Ctrl + 滚轮按光标位置缩放、放大后拖动或滚轮平移，以及适应窗口和原始尺寸；Escape 关闭预览并回到资料详情，未保存的备注保持原样。音视频使用播放控件，打开时不自动播放，关闭后停止。已经下载的论文另有「阅读已下载的论文」入口。大文本或 Office 文件沿用预览范围提示；不支持的格式可以在关联应用中打开，失败会显示原因。预览和阅读均不调用模型。

## 外部接入

内置网页浏览使用本机安装的 **ego lite**，网页在它的原生窗口中打开；右侧面板继续显示本地 HTML、PDF 和图片预览。首次使用先完成 ego lite 的设置向导，浏览器数据是否导入由你选择。

MP 自有 Agent 通过 `EgoBrowser.open/observe/act/screenshot` 操作网页，每个保存任务使用独立 Task Space；支持中文输入、语义元素定位和页面结果读回。需要登录或人工处理时交接给你，只有你明确要求继续才恢复控制。浏览器控制不会把任务转交给 Codex、Claude Code 等其他 Harness。

普通导航会核对实际网址；页面点击本身不算业务成功。表单写入或发送应指定可读回的结果，例如成功消息或字段值。下载、上传和完整右栏嵌入尚未接入这组工具；原有 `Browser.navigate` 继续用于明确指定的已有外部浏览器窗口。

网络 `Search` 在设置 `EXA_API_KEY` 环境变量后使用 Exa Search：每次最多五条结果，返回出处、有限摘录与服务端报告的实际费用。没有密钥时沿用 DuckDuckGo。检索由 MP 自己的主代理和子代理分工执行，不调用 Exa Agent Ultra 的远端执行循环。

`integrations/` 提供外部客户端的配置示例和可选提示词投递接口。
这些接口用于用户明确选择的外部客户端，不是 Magic Pointer 任务执行的必要依赖。
Figma 插件的构建和真实应用限制见 [已知限制](KNOWN_LIMITATIONS.md)。

## 排障

提交问题时附上应用版本、平台、复现步骤和可公开的错误信息。
源码目录执行 `npm run diag:collect` 可收集诊断材料；分享前检查其中的本机路径和任务内容。
模型失败、限流、目标失效和应用不支持会以实际错误呈现。
