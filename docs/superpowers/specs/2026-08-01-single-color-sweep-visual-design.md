# Magic Pointer 单色光带视觉规格

日期：2026-08-01  
状态：用户已确认视觉方向 C

## 目标

复刻参考图中的鼠标拖拽光带：它是一条单一纯蓝色的连续带，不是多层发光效果。自由曲线不得在急转弯处产生三角毛刺、正交尖刺或局部异常增宽。

## 横截面

- 全部像素使用同一个 RGB 色值；只允许 alpha 变化。
- 中央主体为平坦、均匀的纯色平台，不设置浅色细核。
- 上下边缘仅用约 4–6 DIP 的短距离 alpha 羽化自然消失。
- 不绘制独立外圈 Halo，不使用另一种深蓝或浅蓝叠层。
- 不显示虚线、参考线、轮廓线或任何调试辅助视觉。

横截面使用 flat-top feather，而不是全高斯：中心区域保持稳定不变，只有接近边缘时才通过平滑函数衰减至透明。

## 沿轨迹方向

- 以真实累计弧长计算进度，不按屏幕 X/Y 坐标计算。
- 光标端最实、最清楚；越早画出的轨迹越透明，边缘可略微变软。
- 颜色与饱和度沿轨迹保持一致，不允许尾部变灰蓝或头部变浅蓝。
- 鼠标未松开前，最老尾部保留最低可见度，不能淡到消失。
- 松开后才允许整条轨迹按现有生命周期整体退场。

## 几何与渲染

采用屏幕空间路径距离场（path SDF）或等价的无外扩拐角方案。每个像素依据其到中心轨迹的最近距离计算横截面 alpha，因此不生成 miter 外扩顶点，从结构上消除急弯网格自交和毛刺。

自由路径保留真实拖拽形状，只做抑制采样噪声所需的轻量平滑；不得吸附成直线。路径自交时仍按同一单色 alpha 场合成，不得产生亮色结点。

## 验收条件

1. 急弯、S 弯和小半径回环无三角毛刺或正交尖刺。
2. 截面肉眼看不到内核、主体、Halo 的分层边界。
3. 主体中心为稳定纯色，仅上下边缘柔化。
4. 从旧尾到光标端亮度连续递增，无分段跳变。
5. 按住期间最老尾部仍可见；松开后才整体消退。
6. 输出中不存在虚线或任何辅助标记。
7. 只调整蓝线渲染，不改变 overlay 输入、手势点、坐标或提交生命周期。

## 范围

实现范围限制在蓝线渲染器及其针对性测试、视觉夹具；不修改手势交互范式、语音、气泡、Agent 路由或其他 UI。
