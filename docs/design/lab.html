四 · 每条设置都长这样（这是"高级感"真正的来源）

名称 + 一句人话 + 当前值 + 默认值角标。人话那一行解释的是后果，不是复述控件名——"上限就是延迟"是实测出来的因果，"设置最大 token 数"是废话。写不出后果的设置项，说明它不该暴露给用户。
