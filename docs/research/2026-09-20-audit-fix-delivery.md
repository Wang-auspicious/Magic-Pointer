## Jev 接入和取舍

使用本机现有 OpenCode 认证，固定免费模型 `jev-1.13-free`。真实请求费用字段为 0；不写入仓库密钥，不自动切换付费模型。候选选择是只读建议，点击/输入仍执行原有租约、授权与读回。

`search_ui` 的本地匹配为零时，同次调用可附带 Jev 建议；`choose_ui_target` 提供显式候选判断接口。唯一精确名称完全本地处理，连 HTTP 客户端都不创建。语义请求前台最多等待 900 ms，包括连接初始化；持久连接复用、单请求在途、25 ms 取消轮询。大于 64 个候选要求显式缩小范围，低置信度、超时或错误返回原候选。

最小六例对照记录在 [Jev 接入报告](2026-09-20-jev-integration.md) 和 [原始结果](2026-09-20-jev-comparison.json)：语义暖请求约 594–734 ms，冷请求 1891 ms；一例中文语义置信度 0.66，接口选择放弃而不是猜测。主模型同六例批量回答 6031 ms 且全部正确。这是候选判断对照，不是完整 Computer Use 成功率或端到端倍率。
